Loop Hunter

Flipped-classroom game on flow graphs: spot entry nodes, back edges, loop headers and loop bodies.

Flow graph

Nodes are basic blocks. A directed edge A → B means control can pass from A to B. One node is the entry (no incoming path from outside).

Dominator

Node d dominates n if every path from the entry to n goes through d. Every node dominates itself.

Back edge

An edge u → v where v dominates u. Quick test: run a DFS from the entry; a back edge points to an ancestor still on the stack and that ancestor must dominate the source.

Loop header (entry point)

The target v of a back edge. It is the single way into a natural loop, and it dominates every node in the loop.

Natural loop

For back edge u → v: the loop is v plus every node that can reach u without passing through v.

Trap: irreducible graphs

A cycle with two entries has no header that dominates the cycle, so it has no back edge, even though a DFS finds a retreating edge.

Self-check before class

1. In a while loop, which block is the header: the condition test or the body?
2. Can a graph have a cycle but no back edge?
3. If a loop has two back edges to the same header, is it one loop or two?

Answers: the condition test; yes (irreducible); one natural loop (the union), found by combining both back edges.
